# Retail Business Analysis Using SQL

## Project Overview
This project analyses retail business performance using SQL queries and business intelligence techniques on the Global Superstore dataset.

## Tools Used
- SQL
- SQLite
- DB Browser for SQLite

## Analysis Performed
- Total sales analysis
- Profit analysis
- Category performance analysis
- Regional revenue analysis
- Monthly sales trend analysis
- Top customer analysis
- Product profitability analysis

## Key Insights
- Certain regions generated significantly higher revenue and profitability.
- Technology products delivered stronger profit performance.
- Sales trends varied across different time periods.
- A small number of customers contributed a large percentage of total revenue.

## Business Recommendations
- Focus marketing efforts on high-value customers.
- Optimise inventory for profitable product categories.
- Monitor regional performance for growth opportunities.
- Use monthly sales trends to improve forecasting and planning.
